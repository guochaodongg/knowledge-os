03 架构设计

系统架构与设计模式，从单体到分布式。advanced

📐 架构原则

  • 高内聚、低耦合，关注点分离
  • KISS / YAGNI：避免过度设计
  • 为变化而设计：识别稳定点与易变点

🌐 分布式系统

  • CAP 定理与一致性模型（强一致 / 最终一致）
  • 分布式事务：2PC、TCC、Saga
  • 共识算法：Raft、Paxos 的工程应用
  • 服务治理：注册发现、熔断、限流、降级

⚡ 高并发设计

  • 多级缓存：本地缓存 → 分布式缓存 → 数据库
  • 异步削峰：消息队列、事件驱动
  • 无状态水平扩展与读写分离

🔄 架构演进

阶段形态适用规模
单体架构单应用 + 数据库初创 / MVP
垂直拆分按业务拆应用业务增长期
微服务服务化 + 治理体系大规模团队协作
服务网格 / Serverless基础设施下沉云原生成熟期
