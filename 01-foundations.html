01 基础知识

核心基础，是所有技术的根基。beginner

🖥️ 操作系统

进程与线程、内存管理、文件系统、I/O 模型等核心概念。

  • 进程 / 线程 / 协程的区别与适用场景
  • 虚拟内存、页表与缺页中断
  • 文件系统与磁盘 I/O

从 TCP/IP 四层模型到 HTTP/3，理解数据如何在网络中传输。

  • TCP 三次握手 / 四次挥手、拥塞控制
  • HTTP/1.1 → HTTP/2 → HTTP/3 演进
  • DNS、CDN 与负载均衡

🧩 算法与数据结构

数据结构与经典算法，工程能力的基本功。

  • 数组、链表、哈希表、树、堆、图
  • 排序、二分、动态规划、贪心
  • 复杂度分析与取舍

🗄️ 数据库

关系型与 NoSQL 数据库的原理与实践。

  • SQL 优化与执行计划
  • 事务 ACID、隔离级别、MVCC
  • 索引原理（B+ 树）与分库分表
